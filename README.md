# Spark project MS Big Data Télécom : Kickstarter campaigns

Spark project for MS Big Data Telecom based on Kickstarter campaigns 2019-2020

## Launch the project

you need to define the `SPARK_HOME` environment variable that points to your spark installation folder before running the project.

```sh
git clone https://github.com/aksl20/spark_project_kickstarter_2019_2020.git
cd spark_project_kickstarter_2019_2020
./build_and_submit.sh [Preprocessor or Trainer]
```
